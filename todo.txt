DYNAMIC EASTER EGG
- Instead of hardcoding `EASTER_EGG_MAP` as well as the Konami code sequence, 
have it be indicated by the map itself. Or maps in this instance, since we 
have three elevator maps.

RECURSIVE MAP LOADING
- Consider loading maps recursively from the initial map. The game doesn't have 
a lot of maps, so it's okay. You can add a max amount for the initial load if 
you want. I personally have 12 maps, so maybe the max is 15. Also, don't forget 
to call `glfwPollEvents()` in between consecutive map loads, or the OS will 
think the app crashed.
